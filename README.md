# OpenQuick

A new Rust monorepo for an independent implementation informed by public Amazon Quick and QuickSight documentation.

The first control-plane implementation is under development. AgentGateway, identity providers, MicroVM workers, and BI integrations are not available yet.

This repository has no project license selected. No license grant is implied; the owner will choose the project license separately.

This is newly written work. No inaccessible archive or scaffold from another environment has been imported.
